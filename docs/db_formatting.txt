	"question": <"Question here">,

Typing Format
{
	"word": <insert word>,
	"timer": <insert time to type here>,//this is how long the player has to type correctly
	"fact": <Fact here>,//This will be a fact about the word being typed, such as "A database is a collection of data that can be queried"
}
